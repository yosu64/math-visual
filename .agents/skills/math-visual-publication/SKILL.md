# math-visualへの掲載

- 科目別ディレクトリへHTMLを置き、`index.org`と公開`index.html`の両方にリンクを載せる。
- **各科目・同じ教科書の教材一覧は、教科書の本文ページの昇順にする。追加日・更新日順で先頭へ差し込まない。** 同じページなら例題・問題の順、それも同じなら既存順を保つ。
- 教科書本文のページ番号を原本で確認する。画像ファイル名・PDF通し番号・教師用朱註ページを本文ページと混同しない。未確認ページは推測せず未確認として末尾に置く。
- `PAGE`・公開日・更新日を区別し、既存教材の日時や深いリンクを保持する。ページ順への並べ替えだけで教材の更新日を変更しない。
- 授業用アニメーションは既存のレイアウト・操作に合わせる。ユーザーが不要とした下部の長い解説は追加しない。教材画像や教師用注記を公開HTMLへ埋め込まない。
- トップのPick Upなど一覧以外の既存要素を保持する。現在のEmacs生成器は全体再生成で独自要素を落とす可能性があるため、一時出力との比較で必要な科目一覧だけを反映する。
- 数学的性質、JS構文、操作とリンク、ページ順、旧リンクの保持を検証する。公開後は実URLからHTMLとトップリンクを読み戻す。公開権限やマージ条件はこのSkillでは付与しない。
