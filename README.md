# Math Visual

数学の概念を視覚的に理解するための教材集です。  
高校数学（数I・II・III・A・B・C）を中心に、直感的な理解を補助する教材を公開しています。

## 公開ページ
https://yosu64.github.io/math-visual/

## 内容
- 各分野ごとのインタラクティブ教材
- グラフ・立体・確率分布などの可視化
- 授業での使用を想定した設計

## 記事の入口画像

[画像候補の生成・本人確認・採用](docs/image-generation.md)の仕組みを用意しています。
計画の作成と匿名テストはAPIを使いません。実生成には、専用キー、確認済みの費用見積り、
対象計画への課金承認が必要です。採用とサイト公開は別の工程です。

記事一覧の生成・Pick Upの保持については[生成器の説明](tools/README.md)を参照してください。
